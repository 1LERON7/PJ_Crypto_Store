# Web3 Game Store

A full-stack educational web application for purchasing games using cryptocurrency.

## About

Web3 Game Store is a full-stack project developed as part of my Software Development studies.

The application simulates an online game store where users can browse and purchase games using cryptocurrency through MetaMask.

The project combines a React frontend, an ASP.NET Core backend, and smart contracts written in Solidity.

## Features

- Game catalog
- User registration and authentication
- Cryptocurrency payments
- MetaMask integration
- Custom test token
- Solidity smart contracts
- Admin panel
- User panel
- Product management
- User management
- Payment management
